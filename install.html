🤖 Android (Chrome)

  1. เปิดลิงก์ด้วย Chrome
  2. กดปุ่ม 📲 ติดตั้งแอป ในแอป หรือเมนู ⋮ → ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก
  3. กด ติดตั้ง — ไอคอน RoofAngle จะขึ้นที่หน้าจอ

🍎 iPhone / iPad (Safari)

  1. เปิดลิงก์ด้วย Safari
  2. กดปุ่ม แชร์ ⬆️ ด้านล่าง
  3. เลือก เพิ่มไปยังหน้าจอโฮม แล้วกด เพิ่ม
  4. เปิดแอปจากไอคอน แล้วกด “เริ่มวัด” → อนุญาตเซนเซอร์
ติดตั้งแล้วใช้งานออฟไลน์ได้ · เข็มทิศให้วัดห่างแปเหล็ก/เมทัลชีท ~1 เมตร
