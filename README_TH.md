# Roof Clinometer + Bubble Level (งานติดตั้งโซล่าเซลล์)
- เปิด index.html ผ่าน **HTTPS** บนมือถือ (เปิดเป็นไฟล์/http เซนเซอร์จะไม่ทำงาน) กด "เริ่มวัด" (iPhone จะขออนุญาต)
- แท็บ วัดมุม: วางขอบมือถือตามแนวแป/แผ่นหลังคา → มุม°, %, ยกต่อ 1 ม., X:12, 1:N · HOLD, ตั้งศูนย์ (วางบนพื้นราบ), มุมเป้าหมาย (เขียว ±1°, ส้ม ±3°, แดง) + เสียง/สั่น
- แท็บ ลูกน้ำ: วางราบ, เขียวเมื่อ ±0.5°
- แท็บ โซล่า: ทิศหน้าหลังคา (ถอยห่างโลหะ), มุมแนะนำ ≈ ละติจูด หันใต้ (ไทย ~10–18°, อย่างน้อย 5°), ผลผลิตเป็น **ค่าประมาณ** — ออกแบบจริงใช้ PVGIS/PVWatts
- แท็บ ประวัติ: บันทึก/ลบ/ส่งออก CSV (เก็บในเครื่อง localStorage)
- ติดตั้งเป็นแอป: เมนูเบราว์เซอร์ → "เพิ่มไปยังหน้าจอหลัก"

## v3 — แท็บ AR ดวงอาทิตย์ (ใหม่)
- กด "📷 เปิดกล้อง AR" (iPhone จะขอสิทธิ์เซนเซอร์/กล้อง) ถือมือถือตั้งตรง → เห็นเส้นทางดวงอาทิตย์ซ้อนบนภาพกล้อง
- เส้นสี: ส้ม=ครีษมายัน 21 มิ.ย., เขียว=วิษุวัต 20 มี.ค./22 ก.ย., ฟ้า=เหมายัน 21 ธ.ค., ชมพู=วันที่เลือก, ขาว=วันที่กำหนดเอง · จุด+ตัวเลข=ชั่วโมง · เส้นประขาว=เส้นชั่วโมงทั้งปี (analemma) · วงกลมบนขอบฟ้า=จุดขึ้น/ตก
- แถบเลื่อน วันในปี / เวลา → ย้ายดวงอาทิตย์ แสดง Az/Alt
- เช็กเงา: เล็งกากบาทที่ขอบบนต้นไม้/ตึก กด "➕ มาร์กจุด" หลายจุด → ช่วงเส้นที่โดนบังเป็นสีแดงประ + สรุปชั่วโมงที่บังและ % พลังงานที่เสีย (ค่าประมาณ ถ่วง sin(alt))
- เครื่องคิดเงา: สูง H, ระยะ D, ความสูงหลังคา → ความยาวเงาและถึงหลังคาไหม
- คาลิเบรต: หมุนมือถือเป็นเลข 8 ห่างโลหะ · ปุ่ม "🎯 เล็งดวงอาทิตย์จริง" ตั้ง offset อัตโนมัติ · ปรับ FOV (ค่าเริ่ม 60°) · ความแม่นยำเข็มทิศ ±5–10°
- ไม่มีกล้อง/เซนเซอร์ (เช่นคอมพิวเตอร์) → แสดงมุมมอง 2D โดมท้องฟ้า · ตำแหน่ง GPS หรือกรอกเอง (ค่าเริ่ม กรุงเทพ 13.75, 100.5)
- คำนวณตำแหน่งดวงอาทิตย์แบบ NOAA (sun.js) ทำงานออฟไลน์ได้หลังเปิดครั้งแรก
